ScienceQtech Employees Performance Mapping

Prepared By: Ishaan Singh

Project Overview

Analyzed employee, project, salary, experience, performance, and Data Science team data for ScienceQtech using MySQL. The project extends the original course-end assignment into a 16-question SQL analysis covering employee performance, compensation, project allocation, database relationships, and query optimization.

Project Components:

1. SQL Project & Dataset: MySQL project containing the emp_record_table, proj_table, and data_science_team datasets, along with 16 SQL queries covering business-oriented analysis and database operations.

2. SQL Project Report: Comprehensive report containing the Executive Summary, 16 questions, SQL output screenshots, and factual results from each analysis.

3. Project Guidelines: Original assignment brief outlining the ScienceQtech scenario, business requirements, datasets, and required SQL analysis tasks.

4. Entity Relationship Diagram (ERD): Database ERD illustrating the relationships between the employee, project, and Data Science team tables.

Tools & Techniques Used:

MySQL | MySQL Workbench | SQL | Data Analysis | Data Modeling | ERD | JOINs | CTEs | Subqueries | Window Functions | CASE Statements | Aggregation | Views | Indexing | EXPLAIN | Date Functions | GROUP BY

How to Explore:

1. Review the Project Guidelines to understand the original business objectives, datasets, and analysis requirements.

2. Open the SQL file to review the 16 SQL queries and their implementation.

3. View the ERD to understand the database structure and relationships between the tables.

4. Read the SQL Project Report to review the 16 questions, output screenshots, and corresponding results.
